# Analysis of Customer Behaviour-Data Analytics Project

## 📌Project Overview

This project demonstrates an end-to-end Data Analytics workflow, starting from raw data extraction to actionable business insights. The analysis was performed using Python, MySQL, and Power BI to clean, explore, analyze, and visualize the dataset.

The project includes:

* Data loading and preprocessing using Python
* Exploratory Data Analysis (EDA)
* Data cleaning and transformation
* SQL-based analysis using MySQL
* Interactive dashboard creation in Power BI
* Final business insights and reporting

---

## Dataset

The dataset contains structured business/customer data used for analysis and reporting purposes.

**Key Features:**

* Customer Information
* Transaction Details
* Product/Category Data
* Sales and Revenue Metrics
* Other relevant business attributes

## Project Workflow

### 1. Data Loading

* Imported dataset into Python using Pandas.
* Inspected dataset structure and data types.

### 2. Exploratory Data Analysis (EDA)

* Analyzed distributions and trends.
* Identified missing values and outliers.
* Generated summary statistics.
* Created visualizations to understand patterns.

### 3. Data Cleaning

* Handled missing values.
* Removed duplicate records.
* Corrected inconsistent data formats.
* Prepared clean data for analysis.

### 4. SQL Analysis (MySQL)

* Imported cleaned data into MySQL.
* Executed SQL queries to extract business insights.
* Performed aggregations, filtering, joins, and trend analysis.

### 5. Power BI Dashboard

* Connected Power BI to the processed dataset.
* Built interactive dashboards and KPI visualizations.
* Enabled filtering and drill-down analysis.

### 6. Reporting

* Summarized key findings.
* Presented actionable insights derived from the analysis.

## 🛠️How to Run

### Prerequisites

Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn mysql-connector-python sqlalchemy
```

### Steps

1. Clone the repository:

```bash
git clone <repository-link>
```

2. Open the Jupyter Notebook.

3. Load the dataset into Python.

4. Run the EDA and data cleaning scripts.

5. Import the cleaned data into MySQL.

6. Execute the SQL queries provided in the project.

7. Open the Power BI (.pbix) file to view the dashboard.
